## About the Project

The EWaste Dashboard is a centralized platform developed to present academic submissions in an organized and accessible format. It provides a simple interface through which assignments and supporting documents can be viewed.

## Dashboard Categories

- **Internal Assessment (ISA):** Class assignments and internal assessment submissions.
- **End Semester Examination (ESE):** Reports, documents, and examination-related submissions.
- **Additional Activities:** Case studies, research papers, and other academic activities.
- **Other Documents:** Supporting reference materials.

## Features

- Clean and user-friendly interface.
- Organized assignment categories.
- PDF document preview.
- Easy access to academic submissions.
- Responsive layout for different screen sizes.
